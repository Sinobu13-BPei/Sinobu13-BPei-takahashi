高橋二二郎
1908–1989

新潟・畔屋の歴史から、岡谷の鍛冶修業、横須賀・館山の海軍技術兵、鶴見の石油産業、1945年の舞鶴、そして舞岡で家族を待っていた祖父まで。

技術 × 規律 × 信仰 × 郷里 × 優しさ
静かな規律を持ち、言葉ではなく日々の行動で愛情と責任を示した、穏やかで優しい技術者。

01｜史料を混ぜない

家族史は、確定した事実・公的史料・口伝・仮説を分けて読む。

A一次資料

戸籍、軍歴表、履歴書、位牌、家蔵文書など。当時に作成された原記録。

B公的・研究史料

自治体史、学校沿革、海軍公報、企業史、研究論文など。

C口述史

本人を知る家族・親族の記憶。捨てずに記録し、事実と区別する。

D研究仮説

A〜Cをつなぐ解釈。未読文字や不明点を断定せず、検証可能な形で残す。

公開版のプライバシー方針：故人と歴史資料を中心に掲載し、存命の可能性がある親族は実名・詳細住所・詳細生年月日を原則省略しています。

家に残る口伝

祖先は矢田城・黒滝城で料理や神事に関わった、上杉家移封時に柏崎へ残った、妙高山参詣や「二足四足」の禁忌があった、という語りが残る。

まだ証明できないこと

戦国期の「高橋某」、武士・被官であったこと、古代高橋朝臣との血統接続。江戸期の人名史料、真珠院過去帳、検地帳・名寄帳が鍵。

03｜高橋二二郎 基本プロフィール

1908–1989

1908年8月20日、畔屋生。1989年5月2日、80歳で死去。父・貞吉、母・スミ。妻・大野イネ。戒名「仁道恭心居士」。

人物の記憶 C

約173cm、痩せ型。将棋が強い。口数は少ない。晩年はいつもニコニコ。毎日きっちりした生活。

人生の中心語

鍛冶・金属加工／機関・機械修理／石油産業／家族を待つ・見守る／神棚・仏壇・日限地蔵。

05｜岡谷から横須賀・館山へ ― 技術の連続性

1923–1928｜岡谷 A?

鍛冶見習徒弟として約5年半修業。勤務先は「増澤」系の製作所・商店が有力仮説。正式名は徒弟名簿等で確定する。

1929｜横須賀 A?

横須賀海軍航空隊勤務。三等機関兵と読める。機関工業技倆査定「鍛冶」第三級相当の可能性。配置は「金属工業員」。

1930–1931｜館山 A

館山海軍航空隊へ転勤。金属工業員。1930年11月1日、海軍二等機関兵。1931年11月に現役満期へ。

岡谷の鍛冶 → 海軍の金属工業員 → 東邦石油の機械修理工 → 1945年の艦艇艤装関係 → 戦後の石油設備。職業技能の連続性は強く見えるが、各段階の因果関係は史料ごとに確認する。

06｜中国の船上記憶 ― いつ、どこだったのか

口伝 C

「中国で船からは降りなかった。河口付近の川に死体がたくさん流れていた。嫌な思いをした。」

現段階の判断 D

時期・場所は未確定。1932年・1937年の上海戦は情景と合うが、既知の軍歴との整合が弱い。1929–1931年の短期派遣・便乗記録を優先して調査する。

07｜1934–1945｜鶴見 ― 東邦石油と家庭

1934年7月1日 A

横浜市鶴見区大黒町の東邦石油株式会社へ「機械修理工」として入社したと履歴書から読める。25歳。

企業史 B

東邦石油は1933年11月設立。1934年は石油業法施行期。京浜臨海部の石油産業で機械技術者として働いた。

1935年9月19日 A

大野イネと婚姻。鶴見区で婚姻届受理。

1938–1945 A

鶴見区生麦町が一家の重要な生活拠点。勤務先＝大黒町、家庭＝生麦という「鶴見生活圏」が見えてくる。

現在の西寺尾「東邦石油合同会社」と戦前の東邦石油株式会社の承継関係は未証明。同名だけで同一法人と断定しない。

技能との整合

岡谷の鍛冶、横須賀・館山の金属工業員、東邦石油の機械修理工という経歴から、未成艇の機関・配管・軸系・金属加工等の艤装に関与した可能性はある。

断定しない

具体的な担当部署・作業内容は未確定。また第64号艇は未完成のため、「この艇で中国へ行った」とする可能性は極めて低い。

09｜舞岡の二二郎 ― 家族が覚えている祖父

毎日の型 C

朝起きると、薄くなった頭に残る髪へポマードをつけた。夜は浴衣を寝巻きにし、畳に布団を敷き、ラジカセでNHKラジオを聞きながら眠った。

優しさ C

口数は少ないが、晩年はいつもニコニコ。孫が小学校低学年まで一緒に風呂に入り、いつも体を洗ってくれた。

待つ・見守る C

学校から帰る時間や夕方になると、心配して家の外に立ち、帰りを待っていた。

父として C

長女の記憶では、幼い頃の父・二二郎は厳しかった。若い父と、60代以降の祖父という二つの人物像は両立する。

信仰・習慣 C

神棚に榊、仏壇に線香。4のつく日には日限地蔵尊へ歩いて参詣した。

小さな贈り物 C

戦後、娘へ横浜または元町でエクレアを買って帰ったとの口伝が残る。店・時期は未特定。

10｜イネと二二郎 ― 夫婦の時間

1935–1977

大野イネと1935年に婚姻。戦争と戦後を共に生きた。イネは1977年4月15日に死去。

長福寺のツツジ CD

イネ死去後、二二郎自身が舞岡・長福寺の墓前にツツジを選び植えたとの家族記憶がある。選定理由は語り残されていない。

11｜畔屋「やしき」から広がる家族史

公開版では、存命の可能性がある親族の実名は最小限にしています。

貞吉・スミ

二二郎の父母。貞吉は分家から本家「やしき」へ養子に入ったとの口伝があり、養子元は重要な未解決点。

姉としえ → 長谷川家

新潟の長谷川家へ嫁いだ。大きな蔵、刀・鎧甲冑が多くある家との口伝が残る。旧家・武家系統であるかは未証明。

兄・與一郎

畔屋本家を継承。4男3女の大きな家族へ続いたと伝わる。

二二郎・イネ

鶴見で家庭を築き、戦後は横浜・舞岡へ。子・公二（1945–2010）を含む次世代へ続く。

婚姻ネットワーク

長谷川家・赤堀家・原家・政金家などへ家が広がる。姓だけで上杉家臣系譜等と結ばず、家紋・本籍・墓地・菩提寺で検証する。

次の調査
