# Be Free — 高橋忍、自分史 1972–

高橋忍の公開用デジタル自分史サイトです。

**公開URL:** https://sinobu13-bpei.github.io/Sinobu13-BPei-takahashi/

## 公開方針
- 本人の人生・家族史・仕事史を中心に掲載
- 存命者の住所、電話番号、勤務先の細部、健康診断の数値、保険情報、私的な交友関係などは公開しない
- 記憶に基づく内容は、今後一次資料により訂正する場合があります

## 主なページ
- TIMELINE：1972–2026
- ROOTS：父方・母方の家族史
- CAREER：1997–2026の仕事史
- FAMILY：家族と暮らし
- BE FREE：公開版の自分史本文
